# Etqan Tutor — Brand Kit

اللوجو: «إتقان» بالخط الكوفي المربّع. الحروف هي النظام، والنقط الذهبي هي البيانات، والشبكة هي التقنية.

## الفولدرات

| الفولدر | فيه إيه |
|---|---|
| `01-logo/` | الـ wordmark، والـ lockup الأفقي (للموقع والإيميل)، والـ lockup الرأسي. كل واحد بنسخ: primary / reversed / mono. SVG + PNG شفاف بـ 3 أحجام |
| `02-icon/` | أيقونة «ق» لوحدها (شفافة)، وأيقونة التطبيق بـ 3 خلفيات (أخضر، أخضر غامق، كريمي)، مدورة ومربعة للـ stores |
| `03-favicon/` | favicon.ico + svg + apple-touch-icon + android-chrome + site.webmanifest + `html-snippet.html` جاهز تحطه في الـ `<head>` |
| `04-social-media/` | صور بروفايل 1080 (آمنة لو اتقصت دايرة)، وغلافات Facebook وLinkedIn وX وYouTube، كل غلاف بنسخة فاتحة وغامقة |
| `05-backgrounds/` | خلفيات ديسكتوب، Zoom، موبايل، بوستات 1080×1080 و1080×1350، ستوري، سلايدز، وpattern tiles بتتكرر من غير فواصل |
| `06-stationery/` | كارت بزنس (PNG + PDF للطباعة 3.5×2 inch)، ورق رسمي A4 PDF، ولوجو للإيميل سيجنتشر |
| `07-brand-guide/` | دليل الهوية PDF (9 صفحات) + كل صفحة PNG |

كل ملف PNG له نسخة SVG في فولدر `svg/` جنبه، ودي اللي تفتحها في Figma أو Illustrator لو حبيت تعدّل.

## الخطوط
- **Readex Pro** (عربي + إنجليزي): للواجهة والعناوين والنصوص.
- **Fraunces**: للعناوين التسويقية زي الموقع.

الاتنين مجانيين من Google Fonts. النصوص اللي في الملفات متحولة لـ outlines، فهتظهر صح على أي جهاز حتى لو الخط مش متسطّب.

## ملاحظات
- الكارت والورق الرسمي فيهم placeholders زي `[Full Name]` و`[email]`، عدّلهم من ملفات الـ SVG.
- المسافة الفاضية حوالين اللوجو: مربعين من شبكة الكوفي على الأقل من كل ناحية. أصغر حجم للـ wordmark: ‏96px أو 25mm، وللأيقونة: ‏16px.
- الحروف الكوفي اترسمت يدوي على الشبكة. قبل الطباعة الكبيرة أو تسجيل العلامة التجارية، يُفضّل إن مصمم متخصص في الكوفي يراجعها.

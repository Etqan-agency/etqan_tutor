## Dockerized dev environment shipped (2026-06-14)

- **`just dev`** brings the whole stack behind Traefik subdomains (`*.kaleem.localhost`),
  mirroring the ADR-0019 topology so same-site cookie/CSRF/CORS bugs surface in dev, not
  on staging. All six services verified 200 end-to-end; HMR works through the proxy;
  login sets a `Domain=.kaleem.localhost` cookie; 104 backend tests pass in-container.
- **Containers run as the host UID/GID** (injected by the justfile via `id -u`/`id -g`):
  no root-owned bind-mount files.
- **Two integration fixes discovered and resolved:**
  1. Traefik image upgraded to **v3.6** — v3.3 was incompatible with Docker Engine 29's
     minimum API version and refused to start.
  2. Frontend dev Dockerfiles install pnpm via **`npm i -g pnpm@10.28.0`** (not corepack)
     so pnpm is available to the non-root user without corepack's global-shim dance.
- Developer guide written: `docs/developer-guide/local-dev.md`.

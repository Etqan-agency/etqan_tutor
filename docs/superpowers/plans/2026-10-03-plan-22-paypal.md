# Plan 22 — Slice B3c: PayPal — Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Slice:** B3c
**Requires:** — (no other phase's slice; B3b merged first)

**Goal:** An academy connects its own PayPal account next to Stripe. A family pays an unpaid invoice with
PayPal, the server captures the approved order on return, and PayPal's webhook covers a payer who never
comes back. Refunds and reversals made at PayPal are flagged for an admin. Everything works offline
through B3b's simulator.

**Architecture:**
- **Backend:** PayPal plugs into B3b's `etqan.gateways`, built by Plan 20. No new app, feature or
  permission resource.
  - `etqan/gateways/paypal.py` is a business-free PayPal REST client over `httpx`. It covers OAuth with a
    per-account token cache, Orders v2 and webhook verification, and imports only `etqan.platform`.
  - `providers/paypal.py` puts order creation behind B3b's provider interface and checks the redirect.
  - Gateways' services gain four modules:
    - `services/completion.py`: the one completion function, which Stripe now shares;
    - `services/captures.py`: capture, cancel, `complete_paypal` and the still-payable check;
    - `services/paypal_webhooks.py`: the PayPal webhook;
    - `services/expiry.py`: the daily job, which now reads stale PayPal orders.
  - `GatewayAccount` gains `notes` (both providers) and `webhook_id`, `currency` and `locale` (PayPal).
  - Billing is untouched: its `invoice` purpose and `paypal` payment method exist since Plan 20.
- **Dashboard:**
  - the settings page gains a PayPal card and a notes field on the Stripe card;
  - "Pay online" offers PayPal next to Stripe;
  - the return page captures a pending PayPal checkout, or cancels it when PayPal sends the payer back;
  - the simulator page labels the provider;
  - the checkouts list translates and resolves the two new attention reasons.
- **Off by default:** PayPal sits under B3b's `online_payments` (C-17). The seeded demo academy gets an
  enabled PayPal Sandbox account with placeholder credentials, so the simulator works out of the box.

**Tech Stack:**
- backend: Django 6 / DRF 3.18 / django-tenants 3.14, PostgreSQL 18, Celery beat, `httpx`, `respx`
  (both from Plan 20; no new package), Django's cache (Redis; locmem in tests);
- dashboard: React 19 + TanStack Router/Query + Vite (base `/app/`), react-hook-form + zod 4, i18next;
- e2e: Playwright through the Caddy edge.

**Spec:** `docs/superpowers/specs/2026-10-03-b3c-paypal-design.md`, slice B3c of
`docs/superpowers/specs/2026-10-03-b3-money-depth-design.md`. It builds on:
- B3b, `docs/superpowers/specs/2026-10-03-b3b-online-payments-design.md`, as built by **Plan 20**
  (`docs/superpowers/plans/2026-10-03-plan-20-online-payments.md`). Every path, class and function this
  plan names from `etqan.gateways` or `features/gateways` is Plan 20's;
- Plan 6 billing, Plan 12a roles and Plan 13 feature switches.

## Decisions (gaps the spec left, or departures it needed)

| # | Decision |
|---|---|
| D1 | **The PayPal REST client is `etqan/gateways/paypal.py`, a top-level module of the app, not under `providers/`.** The settings service (`services/accounts.py`) must call PayPal for C-5. Plan 20's `providers/__init__.py` imports `providers/stripe.py`, which imports `services.accounts`, so a client under `providers/` would form an import cycle. `providers/paypal.py` wraps the client for checkouts. The module is added to Plan 20's "other apps reach gateways only through its services" contract. |
| D2 | **Field problems are 400s on their fields**, as Plan 20 D18 decided for B3b. The spec's codes map as follows: <br>• `gateways.incomplete` → 400 on `enabled`; <br>• `gateways.paypal_auth_failed` → 400 on `client_id`; <br>• `gateways.paypal_webhook_unknown` → 400 on `webhook_id`; <br>• `gateways.currency_not_supported` → 400 on `provider`; <br>• `gateways.provider_error` → the platform's `ExternalServiceError` (502, generic message). <br>One refinement: PayPal being unreachable or answering 5xx during C-5's checks is a 502 too, not a 400, because the credentials were never judged. |
| D3 | **New 503 codes** (`UnavailableError`, Plan 20 D3): <br>• `gateways.not_configured`: a PayPal webhook arrives while the account lacks a webhook id or a secret; <br>• `gateways.provider_unavailable`: the remote verification timed out, answered 5xx, or answered 401/403/429. Those last three mean our token is refused or PayPal is busy, and PayPal must retry rather than lose the event. Any other 4xx from verification is a 400. |
| D4 | **One completion function.** `services/completion.finish(checkout, *, transaction_number, paid_minor, paid_currency, mode_matches=True)` holds B3b's completion (B-11's checks in Plan 20's order, then the purpose's `complete`). Plan 20's Stripe `_complete` now calls it, and `complete_paypal` calls it with `mode_matches=True` (C-14). Stripe's behaviour and tests are unchanged. |
| D5 | **"Fee decision" (C-8) is compared as the fee itself.** `still_payable` re-runs `prepare` and recomputes `fee_for(...)`. It refuses when `(amount_minor, currency, fee_minor)` differs from the checkout's. So a changed fee percentage cancels an approved checkout rather than capturing a stale total. An unknown purpose, or a `prepare` that raises any `EtqanError`, is "not payable". |
| D6 | **Finding a PayPal event's checkout (C-12).** The spec's order is kept: `supplementary_data.related_ids.order_id` = `provider_ref`, then `custom_id` = checkout id. Two resource shapes need more, as the spec leaves them open: <br>• `CHECKOUT.ORDER.APPROVED` carries an *order*: its order id is `resource.id`, and its `custom_id` is `resource.purchase_units[0].custom_id`; <br>• `PAYMENT.CAPTURE.REFUNDED` and `REVERSED` carry a *refund*, which names neither. It is found by the capture id in its `rel: "up"` link (`…/v2/payments/captures/<id>`), matched against `transaction_number`. <br>Only `provider="paypal"` checkouts are searched. |
| D7 | **Capture and cancel** are `SELF_SERVICE` in the route table and checked in the service through Plan 20's `checkout_for` (the creator, admins, or staff with `checkout.view_any`; otherwise 404). Both answer 404 for a non-PayPal checkout. They and the PayPal webhook are `transaction.non_atomic_requests` (Plan 20 D9), so PayPal is never called inside a transaction. Both answer 200 with `{status, applied}`. |
| D8 | **Expiry (C-16).** Every PayPal checkout uses the 72 h horizon; Stripe keeps Plan 20's 25 h. Simulated PayPal checkouts, and any without an order id, expire without a read. An `APPROVED` order that is no longer payable becomes `expired` (the spec's "anything else"), not `cancelled`. `expire_stale` moves from `services/checkouts.py` to the new `services/expiry.py`; it keeps its name, its export and its task. |
| D9 | **Simulated PayPal ids:** a simulated order is `ord_sim_<hex>`; a simulated capture is `CAP-SIM-<hex>`. Stripe's `cs_sim_` and `pi_sim_` are unchanged. |
| D10 | **Token cache (C-2):** the key is `gateways:paypal-token:<schema>:<mode>:<first 16 hex of sha256(client id)>`. The cache's tenant key function prefixes the schema again, which is harmless. A token whose `expires_in` is 300 s or less is not cached. The `Credentials` dataclass hides the secret from its `repr`. |
| D11 | **Notes** are at most 2000 characters in the API (`TextField` in the database). |
| D12 | **Seeds:** `tenants` may import only `gateways.services`. A new service, `seed_paypal_account(...)`, writes the PayPal row directly (no C-5 checks) and only when none exists (spec §8). |
| D13 | **Decimals:** `etqan.platform.currency` gains `to_decimal_string(minor, code)`, which B3b's spec §3.3 listed but Plan 20 did not build, and `from_decimal_string(text, code) -> int \| None`. A capture amount that does not parse, or has more digits than its currency allows, reads as `None`, and therefore as `amount_mismatch` (B-11). |
| D14 | **`providers_for` keeps a fixed order, `("stripe", "paypal")`**, instead of Plan 20's `sorted(...)`, which would put PayPal first (§4.2). PayPal takes only its account's currency. |
| D15 | **PayPal's mode reuses `GatewayAccount.Mode`** (`test`/`live`). The dashboard shows "Sandbox"/"Production" under the label "Environment". |
| D16 | **The provider choice** is Plan 20's `PayOnline`, which already renders one button per entry of `can_pay_online`: "Pay online with Stripe" and "Pay online with PayPal". The confirm sheet is unchanged (§6). |
| D17 | **The return page's flag:** TanStack Router parses `?cancelled=1` as the number 1. The route accepts `1`, `"1"` and `true`. With the flag, the page cancels and shows "Not paid" at once, unless the checkout is already completed. "Retry" is a link back to the invoice, where Pay online is. |

## Review Focus

Inputs the spec implies but names no test for. Each one has a test in the task named.

1. **The family comes back twice** (two tabs, or the back button and a reload). The first capture
   completes; the second answers `completed` with no second PayPal call and no second payment. Tested in
   Task 4.
2. **The webhook beats the return page.** `PAYMENT.CAPTURE.COMPLETED` lands first, then the page's
   capture finds the checkout completed and never calls PayPal. Tested in Task 5.
3. **PayPal's amount in another decimal shape:** `"525"` is the same money as `"525.00"` and applies;
   `"525.001"` and `"abc"` are `amount_mismatch` and never crash. Tested in Task 4.
4. **The admin switches mode or client id while a token is cached.** The old token is dropped, and a key
   for the new mode or client id cannot collide with it. Saving only notes keeps the token. Tested in
   Task 2.
5. **A refund at PayPal after an admin already resolved the checkout.** The attention reopens
   (`resolved_at` and `resolved_by` cleared), billing is not touched, and a refund on a checkout that never
   completed is ignored. Tested in Task 5.

```python
"""PayPal's answers, as respx serves them in the gateways tests (B3c)."""

import httpx

SANDBOX = "https://api-m.sandbox.paypal.com"
LIVE = "https://api-m.paypal.com"
TOKEN = f"{SANDBOX}/v1/oauth2/token"
ORDERS = f"{SANDBOX}/v2/checkout/orders"
VERIFY = f"{SANDBOX}/v1/notifications/verify-webhook-signature"
WEBHOOKS = f"{SANDBOX}/v1/notifications/webhooks"


def token_ok(respx_mock, base=SANDBOX, expires_in=32400):
    """PayPal hands out an access token (any number of times)."""
    return respx_mock.post(f"{base}/v1/oauth2/token").mock(
        return_value=httpx.Response(
            200,
            json={
                "access_token": "A21-token",
                "token_type": "Bearer",
                "expires_in": expires_in,
            },
        )
    )


def refused(status: int, issue: str) -> httpx.Response:
    """PayPal's error shape: the issue name sits in details[0]."""
    return httpx.Response(
        status, json={"name": "UNPROCESSABLE_ENTITY", "details": [{"issue": issue}]}
    )


def order_created(order_id: str = "ORDER-1", href: str | None = None) -> httpx.Response:
    """A created order whose payer-action link is ``href`` (Sandbox by default)."""
    link = href or f"https://www.sandbox.paypal.com/checkoutnow?token={order_id}"
    return httpx.Response(
        200,
        json={
            "id": order_id,
            "status": "PAYER_ACTION_REQUIRED",
            "links": [
                {"rel": "self", "href": f"{ORDERS}/{order_id}", "method": "GET"},
                {"rel": "payer-action", "href": link, "method": "GET"},
            ],
        },
    )
```

```python
"""B3c C-1, C-2: PayPal over httpx. The base URL follows the mode, every
call has a 10 s timeout, the token is cached per account until five minutes
before it expires, and a 401 drops it and retries once."""

import json
import logging

import httpx
import pytest
from django.core.cache import cache
from django.db import connection

from etqan.gateways import paypal
from etqan.gateways.tests.paypal_fakes import LIVE
from etqan.gateways.tests.paypal_fakes import ORDERS
from etqan.gateways.tests.paypal_fakes import TOKEN

from etqan.gateways.tests.paypal_fakes import WEBHOOKS
from etqan.gateways.tests.paypal_fakes import refused
from etqan.gateways.tests.paypal_fakes import token_ok

SANDBOX_CREDS = paypal.Credentials(mode="test", client_id="cid", secret="s3cret-value")
LIVE_CREDS = paypal.Credentials(mode="live", client_id="cid", secret="s3cret-value")


def test_the_token_uses_client_credentials_and_is_cached(respx_mock):
    token = token_ok(respx_mock)
    assert paypal.access_token(SANDBOX_CREDS) == "A21-token"
    assert paypal.access_token(SANDBOX_CREDS) == "A21-token"
    assert token.call_count == 1
    request = token.calls.last.request
    assert request.headers["Authorization"].startswith("Basic ")
    assert request.content == b"grant_type=client_credentials"
    assert request.extensions["timeout"]["read"] == paypal.TIMEOUT == 10.0


def test_the_cache_key_names_the_schema_and_mode_but_not_the_client_id():
    key = paypal.token_key("test", "cid")
    assert key.startswith(f"gateways:paypal-token:{connection.schema_name}:test:")
    assert "cid" not in key.rsplit(":", 1)[1]
    assert paypal.token_key("live", "cid") != key
```

```python
"""PayPal's REST API (B3c C-1, C-2; plan D1, D10): Orders v2, OAuth client
credentials and webhook verification over httpx, with no SDK. Every call has
a 10 s timeout. The token is cached per academy, mode and client id until
five minutes before it expires; a 401 drops it and retries once.

Errors carry PayPal's HTTP status and issue name only: never a secret, never
a token, never a request body. This module imports no business app and no
other gateways module, so settings and providers can both use it."""

import hashlib
import logging
from dataclasses import dataclass
from dataclasses import field

import httpx
from django.core.cache import cache
from django.db import connection

from etqan.platform import secrets

BASE_URLS = {
    "test": "https://api-m.sandbox.paypal.com",
    "live": "https://api-m.paypal.com",
}
TIMEOUT = 10.0
TOKEN_MARGIN_SECONDS = 300
# Spec §4.1: what the academy subscribes its webhook to, and all C-12 handles.
EVENTS = (
    "CHECKOUT.ORDER.APPROVED",
    "PAYMENT.CAPTURE.COMPLETED",
    "PAYMENT.CAPTURE.PENDING",
    "PAYMENT.CAPTURE.DENIED",
    "PAYMENT.CAPTURE.REFUNDED",
    "PAYMENT.CAPTURE.REVERSED",
)
SIGNATURE_HEADERS = (
    "PAYPAL-AUTH-ALGO",
    "PAYPAL-CERT-URL",
    "PAYPAL-TRANSMISSION-ID",
    "PAYPAL-TRANSMISSION-SIG",
    "PAYPAL-TRANSMISSION-TIME",
)
logger = logging.getLogger(__name__)


class PayPalError(Exception):
    """PayPal refused or failed. ``status`` is the HTTP status, or None when
    PayPal could not be reached; ``issue`` is PayPal's issue name (for
    example ORDER_ALREADY_CAPTURED), else its error name, else ""."""

    def __init__(self, status: int | None, issue: str = ""):
        self.status = status
        self.issue = issue
        super().__init__(f"{status} {issue}")

    @property
    def unavailable(self) -> bool:
        """PayPal is down or slow rather than refusing: try again later."""
        return self.status is None or self.status >= 500


@dataclass(frozen=True)
class Credentials:
    mode: str
    client_id: str
    secret: str = field(repr=False)


def credentials_of(account) -> Credentials:
    """The account's mode, client id (kept in ``public_key``) and secret."""
    secret = secrets.decrypt(account.secret_enc) if account.secret_enc else ""
    return Credentials(mode=account.mode, client_id=account.public_key, secret=secret)


def token_key(mode: str, client_id: str) -> str:
    digest = hashlib.sha256(client_id.encode()).hexdigest()[:16]
    return f"gateways:paypal-token:{connection.schema_name}:{mode}:{digest}"


def drop_token(mode: str, client_id: str) -> None:
    cache.delete(token_key(mode, client_id))


def _issue(response: httpx.Response) -> str:
    try:
        body = response.json()
    except ValueError:
        return ""
    if not isinstance(body, dict):
        return ""
    details = body.get("details") or []
    if details and isinstance(details[0], dict) and details[0].get("issue"):
        return str(details[0]["issue"])
    return str(body.get("name") or body.get("error") or "")


def _send(method: str, url: str, **kwargs) -> httpx.Response:
    try:
        return httpx.request(method, url, timeout=TIMEOUT, **kwargs)
    except httpx.HTTPError as exc:
        logger.warning("PayPal unreachable: %s", type(exc).__name__)
        raise PayPalError(None, "unreachable") from None


def access_token(creds: Credentials) -> str:
    key = token_key(creds.mode, creds.client_id)
    cached = cache.get(key)
    if cached:
        return cached
    response = _send(
        "POST",
        f"{BASE_URLS[creds.mode]}/v1/oauth2/token",
        data={"grant_type": "client_credentials"},
        auth=(creds.client_id, creds.secret),
        headers={"Accept": "application/json"},
    )
    if not response.is_success:
        issue = _issue(response)
        logger.warning("PayPal refused a token: %s %s", response.status_code, issue)
        raise PayPalError(response.status_code, issue)
    body = response.json()
    token = body.get("access_token") or ""
    if not token:
        raise PayPalError(response.status_code, "no_token")
    ttl = int(body.get("expires_in") or 0) - TOKEN_MARGIN_SECONDS
    if ttl > 0:
        cache.set(key, token, ttl)
    return token


def _authorised(creds, method: str, path: str, body, request_id: str) -> httpx.Response:
    headers = {
        "Authorization": f"Bearer {access_token(creds)}",
        "Content-Type": "application/json",
    }
    if request_id:
        headers["PayPal-Request-Id"] = request_id
    return _send(method, f"{BASE_URLS[creds.mode]}{path}", json=body, headers=headers)


def call(
    creds: Credentials,
    method: str,
    path: str,
    *,
    body: dict | None = None,
    request_id: str = "",
) -> dict:
    """One API call with the cached token; a 401 drops it and retries once."""
    response = _authorised(creds, method, path, body, request_id)
    if response.status_code == 401:
        drop_token(creds.mode, creds.client_id)
        response = _authorised(creds, method, path, body, request_id)
    if response.is_success:
        return response.json() if response.content else {}
    issue = _issue(response)
    logger.warning("PayPal refused %s %s: %s %s", method, path, response.status_code, issue)
    raise PayPalError(response.status_code, issue)


def create_order(creds: Credentials, body: dict, *, request_id: str) -> dict:
    return call(creds, "POST", "/v2/checkout/orders", body=body, request_id=request_id)


def capture_order(creds: Credentials, order_id: str, *, request_id: str) -> dict:
    return call(
        creds,
        "POST",
        f"/v2/checkout/orders/{order_id}/capture",
        body={},
        request_id=request_id,
    )


def get_order(creds: Credentials, order_id: str) -> dict:
    return call(creds, "GET", f"/v2/checkout/orders/{order_id}")


def get_webhook(creds: Credentials, webhook_id: str) -> dict:
    return call(creds, "GET", f"/v1/notifications/webhooks/{webhook_id}")


def verify_signature(
    creds: Credentials, *, headers: dict[str, str], webhook_id: str, event: dict
) -> bool:
    """PayPal's own check of a webhook delivery (C-12): True on SUCCESS."""
    body = {
        "auth_algo": headers["PAYPAL-AUTH-ALGO"],
        "cert_url": headers["PAYPAL-CERT-URL"],
        "transmission_id": headers["PAYPAL-TRANSMISSION-ID"],
        "transmission_sig": headers["PAYPAL-TRANSMISSION-SIG"],
        "transmission_time": headers["PAYPAL-TRANSMISSION-TIME"],
        "webhook_id": webhook_id,
        "webhook_event": event,
    }
    answer = call(creds, "POST", "/v1/notifications/verify-webhook-signature", body=body)
    return answer.get("verification_status") == "SUCCESS"
```

```python
def _check_paypal(account: GatewayAccount) -> None:
    """C-5: a token from this mode's PayPal, then the webhook id must exist.
    PayPal out of reach is a 502 (plan D2): nothing was judged."""
    creds = paypal_api.credentials_of(account)
    try:
        paypal_api.access_token(creds)
    except paypal_api.PayPalError as exc:
        if exc.unavailable:
            raise ExternalServiceError("PayPal") from None
        raise ValidationError(
            "PayPal refused this client id and secret for this environment.",
            field="client_id",
        ) from None
    try:
        paypal_api.get_webhook(creds, account.webhook_id)
    except paypal_api.PayPalError as exc:
        if exc.unavailable:
            raise ExternalServiceError("PayPal") from None
        raise ValidationError(
            "PayPal has no webhook with this id for this account.", field="webhook_id"
        ) from None


def _set_paypal_fields(account: GatewayAccount, change: dict) -> None:
    if "mode" in change:
        account.mode = change["mode"]
    if "client_id" in change:
        account.public_key = change["client_id"]
    if "secret" in change:
        account.secret_enc = secrets.encrypt(change["secret"]) if change["secret"] else ""
    for name in ("webhook_id", "currency", "locale", "notes"):
        if name in change:
            setattr(account, name, change[name])


def _apply_paypal(account: GatewayAccount, change: dict) -> None:
    before = (account.mode, account.public_key, account.secret_enc)
    _set_paypal_fields(account, change)
    if (account.mode, account.public_key, account.secret_enc) != before:
        paypal_api.drop_token(before[0], before[1])  # C-2
    complete = bool(
        account.public_key and account.secret_enc and account.webhook_id and account.currency
    )
    if change.get("enabled") and not complete:
        raise ValidationError(
            "Enter the client id, secret, webhook id and currency first.", field="enabled"
        )
    if "enabled" in change:
        account.enabled = bool(change["enabled"])
    if not complete:
        account.enabled = False
    if account.enabled and not settings.GATEWAYS_SIMULATE:
        _check_paypal(account)
```

```python
def to_decimal_string(minor: int, code: str) -> str:
    """``minor`` as the decimal string a provider reads: 52500 USD -> "525.00"."""
    digits = minor_digits(code)
    if digits == 0:
        return str(minor)
    sign = "-" if minor < 0 else ""
    whole, fraction = divmod(abs(minor), 10**digits)
    return f"{sign}{whole}.{fraction:0{digits}d}"


def from_decimal_string(text: str, code: str) -> int | None:
    """A provider's decimal amount in minor units, or None when it is not a
    finite number with at most the currency's digits (plan D13)."""
    try:
        value = Decimal(str(text))
    except InvalidOperation:
        return None
    if not value.is_finite():
        return None
    minor = value.scaleb(minor_digits(code))
    if minor != minor.to_integral_value():
        return None
    return int(minor)
```

```python
def _money(minor: int, code: str) -> dict:

def order_body(account, checkout, *, return_url: str, cancel_url: str) -> dict:
    code = checkout.currency
    total = checkout.amount_minor + checkout.fee_minor
    items = [
        {
            "name": (checkout.description or str(checkout.pk))[:127],
            "quantity": "1",
            "unit_amount": _money(checkout.amount_minor, code),
        }
    ]
    if checkout.fee_minor > 0:
        items.append(
            {"name": FEE_LINE, "quantity": "1", "unit_amount": _money(checkout.fee_minor, code)}
        )
    return {
        "intent": "CAPTURE",
        "purchase_units": [
            {
                "custom_id": str(checkout.pk),
                "amount": {
                    **_money(total, code),
                    "breakdown": {"item_total": _money(total, code)},
                },
                "items": items,
            }
        ],
        "payment_source": {
            "paypal": {
                "experience_context": {
                    "locale": account.locale or "en-US",
                    "user_action": "PAY_NOW",
                    "shipping_preference": "NO_SHIPPING",
                    "return_url": return_url,
                    "cancel_url": cancel_url,
                }
            }
        },
    }


def payer_action(order: dict, mode: str) -> str:
    """C-10: the payer-action link, only https on PayPal's host for ``mode``."""
    for link in order.get("links") or []:
        if link.get("rel") != "payer-action":
            continue
        href = str(link.get("href") or "")
        parts = urlsplit(href)
        if parts.scheme == "https" and parts.hostname == PAYER_HOSTS[mode] and parts.port is None:
            return href
        break
    logger.warning("PayPal order %s has no acceptable payer-action link", order.get("id", ""))
    raise ProviderError("error")


class PayPalProvider:
    def create(self, account, checkout, *, success_url: str, cancel_url: str) -> Session:
        creds = paypal.credentials_of(account)
        body = order_body(account, checkout, return_url=success_url, cancel_url=cancel_url)
        try:
            order = paypal.create_order(creds, body, request_id=str(checkout.pk))
        except paypal.PayPalError as exc:
            reason = "currency_not_supported" if exc.issue == "CURRENCY_NOT_SUPPORTED" else "error"
            raise ProviderError(reason) from None
        if not order.get("id"):
            raise ProviderError("error")
        return Session(ref=str(order["id"]), url=payer_action(order, account.mode))

    def expire(self, account, ref: str) -> None:
        """An order nobody approved lapses at PayPal by itself."""
        return None
```

```python
"""The one way a checkout completes, whatever the provider (B3b §4.4, B3c
§4.3 step 5, plan D4): B-11's checks first, then the purpose's `complete`.
The caller holds the checkout's row lock and has checked it is not yet

from etqan.gateways import clock
from etqan.gateways.models import Checkout
from etqan.gateways.services.purposes import CompletedCheckout
from etqan.gateways.services.purposes import purpose_named


def attention_for(
    checkout: Checkout, *, paid_minor: int | None, paid_currency: str, mode_matches: bool
) -> str:
    """B-11 in B3b's order: mode, currency, amount, purpose. "" when fine."""
    if not mode_matches:
        return "mode_mismatch"
    if (paid_currency or "").upper() != checkout.currency:
        return "currency_mismatch"
    if paid_minor != checkout.amount_minor + checkout.fee_minor:
        return "amount_mismatch"
    if purpose_named(checkout.purpose) is None:
        return "purpose_unknown"
    return ""


def finish(
    checkout: Checkout,
    *,
    transaction_number: str,
    paid_minor: int | None,
    paid_currency: str,
    mode_matches: bool = True,
) -> None:
    checkout.status = Checkout.Status.COMPLETED
    checkout.completed_at = clock.now()
    checkout.transaction_number = transaction_number
    reason = attention_for(
        checkout, paid_minor=paid_minor, paid_currency=paid_currency, mode_matches=mode_matches
    )
    if reason:
        applied, checkout.attention = False, reason
    else:
        result = purpose_named(checkout.purpose).complete(
            CompletedCheckout(
                id=checkout.pk,
                purpose=checkout.purpose,
                reference_id=checkout.reference_id,
                provider=checkout.provider,
                amount_minor=checkout.amount_minor,
                fee_minor=checkout.fee_minor,
                currency=checkout.currency,
                transaction_number=checkout.transaction_number,
                completed_at=checkout.completed_at,
            )
        )
        applied, checkout.attention = result.ok, result.reason
    checkout.applied = applied
    checkout.save()
```

```python
`complete_paypal`, the one function the capture route, the webhook, the
expiry job and the simulator all finish through. PayPal is never called
under a row lock (C-7): the lock is taken, released, PayPal is called, and
the completion takes the lock again."""

import logging

from django.db import transaction

from etqan.gateways import paypal
from etqan.gateways.models import Checkout
from etqan.gateways.models import GatewayAccount
from etqan.gateways.services import fees

PENDING = Checkout.Status.PENDING
COMPLETED = Checkout.Status.COMPLETED
logger = logging.getLogger(__name__)


def still_payable(checkout: Checkout) -> bool:
    """C-8, plan D5: the purpose would still charge exactly this, now."""
    handler = purpose_named(checkout.purpose)
    if handler is None:
        return False
    try:
        prepared = handler.prepare(checkout.reference_id, checkout.created_by, None)
    except EtqanError:
        return False
    fee = fees.fee_for(
        prepared.amount_minor,
        prepared.currency,
        add_fee=prepared.add_fee,
        provider=checkout.provider,
    )
    return (prepared.amount_minor, prepared.currency, fee) == (
        checkout.amount_minor,
        checkout.currency,
        checkout.fee_minor,
    )


def capture_of(order: dict) -> dict:
    """The order's first capture; an order without one is PayPal's error."""
    units = order.get("purchase_units") or [{}]
    captures = (units[0].get("payments") or {}).get("captures") or []
    if not captures:
        raise paypal.PayPalError(200, "NO_CAPTURE")
    return captures[0]


def complete_paypal(checkout_id, capture: dict) -> Checkout:
    """§4.3 step 5: COMPLETED completes from any state but completed (B-4),
    with B-11's checks against PayPal's decimal amount (C-14); DECLINED fails
    a pending checkout; anything else (PENDING) changes nothing."""
    with transaction.atomic():
        checkout = Checkout.objects.select_for_update().get(pk=checkout_id)
        state = capture.get("status")
        if state == "COMPLETED" and checkout.status != COMPLETED:
            amount = capture.get("amount") or {}
            code = str(amount.get("currency_code") or "")
            finish(
                checkout,
                transaction_number=str(capture.get("id") or ""),
                paid_minor=from_decimal_string(
                    str(amount.get("value") or ""), code or checkout.currency
                ),
                paid_currency=code,
            )
        elif state == "DECLINED" and checkout.status == PENDING:
            checkout.status = Checkout.Status.FAILED
            checkout.save(update_fields=["status"])
        return checkout


def _capture_call(checkout: Checkout) -> dict:
    """C-9: capture with its own request id; an order already captured is
    read and its capture used."""
    creds = paypal.credentials_of(paypal_account())
    try:
        order = paypal.capture_order(
            creds, checkout.provider_ref, request_id=f"{checkout.pk}-capture"
        )
    except paypal.PayPalError as exc:
        if exc.issue != "ORDER_ALREADY_CAPTURED":
            raise
        order = paypal.get_order(creds, checkout.provider_ref)
    return capture_of(order)


def capture_pending(checkout_id, *, refused: str = Checkout.Status.CANCELLED) -> Checkout:
    """§4.3 steps 3 to 5. A checkout no longer payable becomes ``refused``
    and nothing is captured. Raises paypal.PayPalError on a provider failure,
    except ORDER_NOT_APPROVED, which answers the checkout unchanged."""
    with transaction.atomic():
        checkout = Checkout.objects.select_for_update().get(pk=checkout_id)
        if checkout.status != PENDING:
            return checkout
        if not still_payable(checkout):
            checkout.status = refused
            checkout.save(update_fields=["status"])
            return checkout
    try:
        capture = _capture_call(checkout)
    except paypal.PayPalError as exc:
        if exc.issue == "ORDER_NOT_APPROVED":
            return Checkout.objects.get(pk=checkout_id)
        raise
    return complete_paypal(checkout_id, capture)


def _paypal_checkout_for(user, checkout_id) -> Checkout:
    checkout = checkout_for(user, checkout_id)
    if checkout.provider != PAYPAL:
        raise NotFoundError("Checkout", checkout_id)
    return checkout


def capture_checkout(checkout_id, *, user) -> Checkout:
    """The capture route (§4.3): a completed or simulated checkout answers at
    once; a provider failure is a 502 and leaves the checkout as it was."""
    checkout = _paypal_checkout_for(user, checkout_id)
    if checkout.status == COMPLETED or checkout.simulated:
        return checkout
    try:
        return capture_pending(checkout.pk)
    except paypal.PayPalError as exc:
        logger.warning("PayPal capture failed for %s: %s %s", checkout.pk, exc.status, exc.issue)
        raise ExternalServiceError("payment") from None


def cancel_checkout(checkout_id, *, user) -> Checkout:
    """C-11: the payer came back through PayPal's cancel link. Money that
    arrives later is still accepted (B-4)."""
    checkout = _paypal_checkout_for(user, checkout_id)
    Checkout.objects.filter(pk=checkout.pk, status=PENDING).update(
        status=Checkout.Status.CANCELLED
    )
    checkout.refresh_from_db()
    return checkout
```

```python
"""PayPal events (B3c C-12, C-13, §4.4). Checked in the spec's order before
any remote call: a configured account, the five PAYPAL-* headers, a cert URL
on PayPal's API host, JSON, a subscribed type, a checkout in this academy.
Only then does PayPal verify the delivery (two remote calls, so it runs
last). Recorded with their effects in one transaction, as Stripe's are; a
replay finds its row and does nothing."""

import json
import logging
import uuid
from urllib.parse import urlsplit

from django.db import IntegrityError
from django.db import transaction

from etqan.gateways import paypal
from etqan.gateways.models import Checkout
from etqan.gateways.models import GatewayAccount
from etqan.gateways.models import WebhookEvent
from etqan.gateways.services.accounts import paypal_account
from etqan.gateways.services.captures import capture_pending
from etqan.gateways.services.captures import complete_paypal
from etqan.platform.exceptions import UnavailableError

PAYPAL = GatewayAccount.Provider.PAYPAL
APPROVED = "CHECKOUT.ORDER.APPROVED"
CAPTURE_COMPLETED = "PAYMENT.CAPTURE.COMPLETED"
CAPTURE_DENIED = "PAYMENT.CAPTURE.DENIED"
FLAGS = {
    "PAYMENT.CAPTURE.REFUNDED": "provider_refunded",
    "PAYMENT.CAPTURE.REVERSED": "provider_reversed",
}
CERT_HOSTS = frozenset({"api.paypal.com", "api.sandbox.paypal.com"})
# Plan D3: our token refused, or PayPal busy: PayPal must retry, not drop it.
RETRY_STATUSES = frozenset({401, 403, 429})
logger = logging.getLogger(__name__)


class BadEvent(Exception):  # noqa: N818 -- reads as what was received
    """Not PayPal's, or not well formed: answered 400 and never stored."""


def _signature(headers) -> dict[str, str]:
    found = {name: str(headers.get(name) or "") for name in paypal.SIGNATURE_HEADERS}
    if not all(found.values()):
        raise BadEvent("missing headers")
    cert = urlsplit(found["PAYPAL-CERT-URL"])
    if cert.scheme != "https" or cert.hostname not in CERT_HOSTS:
        raise BadEvent("cert url")
    return found


def _parse(raw: bytes) -> dict:
    try:
        event = json.loads(raw)
    except ValueError:
        raise BadEvent("json") from None
    if not isinstance(event, dict) or not event.get("id"):
        raise BadEvent("json")
    return event


def _uuid_or_none(value: str) -> uuid.UUID | None:
    try:
        return uuid.UUID(value)
    except ValueError:
        return None


def _ids(kind: str, resource: dict) -> tuple[str, str, str]:
    """Plan D6: (order id, checkout id, capture id) the resource names."""
    related = (resource.get("supplementary_data") or {}).get("related_ids") or {}
    order_id = str(related.get("order_id") or "")
    custom = resource.get("custom_id")
    if kind == APPROVED:
        order_id = order_id or str(resource.get("id") or "")
        units = resource.get("purchase_units") or [{}]
        custom = custom or units[0].get("custom_id")
    capture_id = ""
    for link in resource.get("links") or []:
        href = str(link.get("href") or "")
        if link.get("rel") == "up" and "/captures/" in href:
            capture_id = href.rstrip("/").rsplit("/", 1)[-1]
    return order_id, str(custom or ""), capture_id


def find_paypal(kind: str, resource: dict) -> Checkout | None:
    """C-12: by order id, then custom_id, then (refunds) the capture id."""
    paypal_checkouts = Checkout.objects.filter(provider=PAYPAL)
    order_id, custom, capture_id = _ids(kind, resource)
    if order_id:
        found = paypal_checkouts.filter(provider_ref=order_id).first()
        if found is not None:
            return found
    key = _uuid_or_none(custom) if custom else None
    if key is not None:
        found = paypal_checkouts.filter(pk=key).first()
        if found is not None:
            return found
    if capture_id:
        return paypal_checkouts.filter(transaction_number=capture_id).first()
    return None


def _verify(account, signature: dict[str, str], event: dict) -> None:
    try:
        ok = paypal.verify_signature(
            paypal.credentials_of(account),
            headers=signature,
            webhook_id=account.webhook_id,
            event=event,
        )
    except paypal.PayPalError as exc:
        if exc.unavailable or exc.status in RETRY_STATUSES:
            raise UnavailableError(
                "PayPal could not verify this event now.",
                code="gateways.provider_unavailable",
            ) from None
        raise BadEvent("verification refused") from None
    if not ok:
        raise BadEvent("not verified")


def _flag(checkout_id, reason: str) -> None:
    """C-13: recorded as attention; billing is not touched."""
    checkout = Checkout.objects.select_for_update().get(pk=checkout_id)
    if checkout.status != Checkout.Status.COMPLETED:
        logger.info("PayPal %s for checkout %s, which never completed", reason, checkout_id)
        return
    checkout.attention = reason
    checkout.resolved_at = None
    checkout.resolved_by = None
    checkout.save(update_fields=["attention", "resolved_at", "resolved_by"])


def _apply(checkout_id, kind: str, resource: dict) -> None:
    if kind == CAPTURE_COMPLETED:
        complete_paypal(checkout_id, {**resource, "status": "COMPLETED"})
    elif kind == CAPTURE_DENIED:
        complete_paypal(checkout_id, {**resource, "status": "DECLINED"})
    elif kind in FLAGS:
        _flag(checkout_id, FLAGS[kind])
    # A pending capture is recorded and changes nothing (C-9).


def process_paypal(raw: bytes, headers) -> None:
    """Raises BadEvent (400), UnavailableError (503) or whatever a purpose
    raises (500, rolled back)."""
    account = paypal_account()
    if not account.webhook_id or not account.secret_enc:
        raise UnavailableError("PayPal is not set up here.", code="gateways.not_configured")
    signature = _signature(headers)
    event = _parse(raw)
    kind = str(event.get("event_type") or "")
    if kind not in paypal.EVENTS:
        return
    resource = event.get("resource") if isinstance(event.get("resource"), dict) else {}
    found = find_paypal(kind, resource)
    if found is None:
        logger.info("PayPal event %s names no checkout here", event["id"])
        return
    _verify(account, signature, event)
    with transaction.atomic():
        try:
            with transaction.atomic():
                WebhookEvent.objects.create(
                    provider=PAYPAL,
                    event_id=str(event["id"])[:255],
                    type=kind,
                    checkout=found,
                )
        except IntegrityError:
            return  # a replay
        if kind != APPROVED:
            _apply(found.pk, kind, resource)
            return
    # §4.4: the event row has committed; capture outside any lock. An order
    # approved but not captured has taken no money: the return page or the
    # expiry job settles it.
    try:
        capture_pending(found.pk)
    except paypal.PayPalError as exc:
        logger.warning("Capture after %s failed: %s %s", APPROVED, exc.status, exc.issue)
```

```python
class PayPalWebhookView(APIView):
    """C-12: PayPal, unauthenticated (so CSRF-free); local checks, then
    PayPal's own verification. Throttled per IP, since each verification
    costs PayPal calls. Non-atomic (plan D7): see urls."""

            return Response({"detail": "Not processed."}, status=500)
```

```python
"""The daily expiry (B3b plan D11, B3c C-16, plan D8). Stripe sessions live
24 h, so a pending Stripe checkout expires after 25 h. An approved PayPal
order stays capturable for about three days, so a real PayPal checkout is
read after 72 h: completed -> completed; approved and still payable ->
captured; anything else -> expired. A PayPal error leaves it for the next
run. Simulated and orderless PayPal checkouts expire without a read."""

import logging
from datetime import timedelta

from django.db.models import Q

from etqan.gateways import clock
from etqan.gateways import paypal
from etqan.gateways.models import Checkout
from etqan.gateways.models import GatewayAccount
from etqan.gateways.services.accounts import paypal_account
from etqan.gateways.services.captures import capture_of
from etqan.gateways.services.captures import capture_pending
from etqan.gateways.services.captures import complete_paypal

STALE_AFTER = timedelta(hours=25)
PAYPAL_STALE_AFTER = timedelta(hours=72)
PENDING = Checkout.Status.PENDING
EXPIRED = Checkout.Status.EXPIRED
PAYPAL = Q(provider=GatewayAccount.Provider.PAYPAL)
logger = logging.getLogger(__name__)


def _settle(account, checkout: Checkout) -> str:
    order = paypal.get_order(paypal.credentials_of(account), checkout.provider_ref)
    state = order.get("status")
    if state == "COMPLETED":
        return complete_paypal(checkout.pk, capture_of(order)).status
    if state == "APPROVED":
        return capture_pending(checkout.pk, refused=EXPIRED).status
    Checkout.objects.filter(pk=checkout.pk, status=PENDING).update(status=EXPIRED)
    return Checkout.objects.get(pk=checkout.pk).status


def settle_stale_paypal(now) -> int:
    stale = list(
        Checkout.objects.filter(
            PAYPAL,
            simulated=False,
            status=PENDING,
            created_at__lt=now - PAYPAL_STALE_AFTER,
        ).exclude(provider_ref="")
    )
    if not stale:
        return 0
    account = paypal_account()
    settled = 0
    for checkout in stale:
        try:
            if _settle(account, checkout) != PENDING:
                settled += 1
        except paypal.PayPalError as exc:
            logger.warning(
                "PayPal order of %s unread (%s %s); next run", checkout.pk, exc.status, exc.issue
            )
    return settled


def expire_stale() -> int:
    """Pending checkouts the job settled; a verified completion still lands
    later (B-4)."""
    now = clock.now()
    count = (
        Checkout.objects.filter(status=PENDING, created_at__lt=now - STALE_AFTER)
        .exclude(PAYPAL)
        .update(status=EXPIRED)
    )
    count += (
        Checkout.objects.filter(PAYPAL, status=PENDING, created_at__lt=now - PAYPAL_STALE_AFTER)
        .filter(Q(simulated=True) | Q(provider_ref=""))
        .update(status=EXPIRED)
    )
    return count + settle_stale_paypal(now)
```

```tsx
const POLL_FOR_MS = 60_000;

function InvoiceLink({

	label: string;

/** B3b §4.5, B3c §4.5: polls every 2 s for up to a minute. A pending PayPal
 * checkout is captured once on arrival; with `cancelled` (PayPal's cancel
 * link, C-11) it is cancelled instead and the page says "Not paid". */
export function ReturnPage({
	checkoutId,
	cancelled = false,
}: {
	checkoutId: string | undefined;
	cancelled?: boolean;
}) {
	const { t } = useTranslation();
	const qc = useQueryClient();
	const { data: me } = useMe();
	const [polling, setPolling] = useState(!cancelled);
	useEffect(() => {
		if (cancelled) return;
		const timer = setTimeout(() => setPolling(false), POLL_FOR_MS);
		return () => clearTimeout(timer);
	}, [cancelled]);
	const { data, isError, refetch, isFetching } = useCheckout(checkoutId, {
		poll: polling,
	});
	const { mutate } = useMutation({
		mutationFn: (id: string) =>
			cancelled ? gatewaysApi.cancel(id) : gatewaysApi.capture(id),
		onSettled: () =>
			qc.invalidateQueries({ queryKey: [...gatewaysKey, "checkout", checkoutId] }),
	});
	const asked = useRef(false);
	useEffect(() => {
		if (asked.current || data?.provider !== "paypal" || data.status !== "pending") {
			return;
		}
		asked.current = true;
		mutate(data.id);
	}, [data, mutate]);

	if (checkoutId === undefined || isError) {
		return (
			<Alert variant="destructive">
				<AlertDescription>{t("gateways.return.missing")}</AlertDescription>
			</Alert>
		);
	}
	if (!data) return <Spinner />;
	const office = me?.role === "admin" || me?.role === "staff";
	const invoiceId = String(data.reference_id);
	const link = (label: string) =>
		data.purpose === "invoice" ? (
			<InvoiceLink office={office} invoiceId={invoiceId} label={label} />
		) : null;
	const paid = data.status === "completed";
	const waiting = !paid && !cancelled && data.status === "pending";
	return (
		<Card>
			<CardContent className="flex flex-col items-start gap-4 pt-6">
				{paid ? (
					<>
						<p className="text-success">{t("gateways.return.paid")}</p>
						{link(t("gateways.return.back"))}
					</>
				) : waiting ? (
					<>
						<p>{t("gateways.return.processing")}</p>
						<Button size="sm" disabled={isFetching} onClick={() => void refetch()}>
							{t("gateways.return.refresh")}
						</Button>
						{link(t("gateways.return.back"))}
					</>
				) : (
					<>
						<p className="text-destructive">{t("gateways.return.notPaid")}</p>
						{link(t("gateways.return.retry"))}
					</>
				)}
			</CardContent>
		</Card>
	);
}
```

```markdown
## 12. Amendments from planning (Plan 22)
```

# Plan 44 — B5e Internal chat (core) — Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Admins, staff, teachers and students chat in one-to-one conversations and office-managed groups. Messages are plain text, with read state, polling, and an unread nav badge. Each student has two chat switches.

**Architecture:** A new tenant app `etqan.chat` (models, services, api) holds four tables: `Conversation`, `Participant`, `Message` and `ChatAccess`. It reads only `identity.services` and `scheduling.services`. The REST API is under `/api/v1/chat/`. The dashboard has a new `features/chat/` with a two-pane `/chat` page, a groups page, a student chat card, and a D27 nav badge. Polling only; there are no websockets.

**Tech Stack:** Django 5 + DRF + django-tenants, pytest; React + TanStack Router/Query, vitest; Playwright.

**Spec:** `docs/superpowers/specs/2026-10-07-b5e-chat-design.md`, with the phase spec `docs/superpowers/specs/2026-10-07-b5-communication-design.md`.

**Requires:** — no other phase's slice.

**Branches:** `feat/b5e-chat` in backend, dashboard and meta, stacked on `feat/b5a-communication`, so the B5 marker lines do not conflict. They are rebased onto `origin/main` / `origin/master` once B5a merges.

```python
"""Who is in chat (spec B5e E-2, E-3)."""

from etqan.chat.models import ChatAccess

CHAT_ROLES = ("admin", "staff", "teacher", "student")
OFFICE = ("admin", "staff")


def access_of(user) -> ChatAccess:
    return ChatAccess.objects.filter(user=user).first() or ChatAccess(user=user)


def in_chat(user) -> bool:
    if user is None or not user.is_active or user.role not in CHAT_ROLES:
        return False
    return user.role != "student" or access_of(user).chat_enabled


def can_start(user) -> bool:
    if not in_chat(user):
        return False
    return user.role != "student" or access_of(user).can_start


def in_chat_ids(users) -> set[int]:
    """The ids of ``users`` (User objects) who are in chat: one query."""
    users = [u for u in users if u.is_active and u.role in CHAT_ROLES]
    students = [u.pk for u in users if u.role == "student"]
    off = set(
        ChatAccess.objects.filter(user_id__in=students, chat_enabled=False).values_list(
            "user_id", flat=True
        )
    ) if students else set()
    return {u.pk for u in users if u.pk not in off}


def set_access(user, *, chat_enabled=None, can_start=None) -> ChatAccess:
    row, _ = ChatAccess.objects.get_or_create(user=user)
    fields = {k: v for k, v in (("chat_enabled", chat_enabled), ("can_start", can_start)) if v is not None}
    for key, value in fields.items():
        setattr(row, key, value)
    if fields:
        row.save(update_fields=list(fields))
    return row
```

`start_direct`:

```python
@transaction.atomic
def start_direct(user, other_id):
    if not access.can_start(user):
        raise ValidationError("You cannot start conversations.", field="user")
    if not contacts(user).filter(pk=other_id).exists():
        raise ValidationError("You cannot start a conversation with this person.", field="user")
    low, high = sorted((user.pk, other_id))
    key = f"{low}:{high}"
    existing = Conversation.objects.filter(direct_key=key).first()
    if existing:
        return existing, False
    try:
        with transaction.atomic():
            conversation = Conversation.objects.create(
                kind=Conversation.Kind.DIRECT, direct_key=key, created_by=user
            )
            Participant.objects.bulk_create(
                [Participant(conversation=conversation, user_id=i) for i in (low, high)]
            )
    except IntegrityError:
        return Conversation.objects.get(direct_key=key), False
    return conversation, True
```

```python
def mark_read(user, conversation_id, up_to):
    me = participant(user, conversation_id)
    if not Message.objects.filter(conversation_id=conversation_id, pk=up_to).exists():
        raise ValidationError("Unknown message.", field="up_to")
    Participant.objects.filter(pk=me.pk).filter(
        Q(last_read_message_id__isnull=True) | Q(last_read_message_id__lt=up_to)
    ).update(last_read_message_id=up_to)


def unread_by_conversation(user, conversation_ids):
    return dict(
        Message.objects.filter(
            conversation_id__in=conversation_ids,
            conversation__participants__user=user,
            deleted_at__isnull=True,
        )
        .exclude(sender=user)
        .filter(
            Q(conversation__participants__last_read_message_id__isnull=True)
            | Q(pk__gt=F("conversation__participants__last_read_message_id"))
        )
        .values("conversation_id")
        .annotate(n=Count("id"))
        .values_list("conversation_id", "n")
    )
```

The two `participants` joins must refer to the same row. Use a `FilteredRelation("conversation__participants", condition=Q(conversation__participants__user=user))`, or a subquery on `Participant`, and test it with two participants.

`send` does the following:
- strips the body and checks it is 1–4000 characters (400 `body`);
- for a direct conversation whose other participant is out of chat, raises `ConflictError("This person can't receive messages.", code="chat.recipient_unavailable")`;
- creates the message;
- updates `Conversation.last_message_at`;
- sets the sender's own `last_read_message_id` to the new id.

`delete` sets `deleted_at` and `body = ""`, and returns 404 for anyone but the sender.

## B9b rulings (made during plan 23)
- ETQAN_SECRETS_KEY optional in production — missing key → system check WARNING (not error) and two-factor setup refused with a clear 503; existing behaviour unaffected — a required env var would break every deploy (staging sim) that lacks it before anyone uses 2FA; spec S-2a amended in the meta repo — cost if wrong: an academy can't enable 2FA until Etqan sets the key.
- a successful sign-in clears only the per-identifier failure counter, not the per-IP one — clearing the IP counter would let one valid account reset a password spray — cost if wrong: an office IP that fails 50 times in an hour waits out the window.
- wrong second-factor codes also count as failures of that user's identifier (LOGIN_ID), so restarting the pending sign-in cannot give unlimited code guesses (~10/hour) — S-14 accepted only the per-round 5 — cost if wrong: a user who mistypes codes is locked for up to an hour.
- wrong codes on me/2fa/confirm, recovery-codes and disable count against a per-user failure counter (LOGIN_ID key user:{pk}); blocked → 429 — a stolen session must not brute-force turning 2FA off — cost if wrong: a user mistyping 10 codes waits up to an hour.
- admin_disable logs mfa_disabled even when the person had no authenticators — audit of intent — cost if wrong: an extra log row.
- signin.complete() (a real sign-in) drops any etqan.impersonator key even when the user is the same — a real sign-in is never an impersonation — cost if wrong: none.
- me PATCH of phone refused while impersonating (phone is a sign-in identifier under S-6) — cost if wrong: an admin can't fix a phone while signed in as the person (they edit it from the people page instead).
- the link exchange (quick-login/) answers the same 400 while the quick_login switch is off — turning the feature off must stop outstanding links (FT-4: off hides) — cost if wrong: none.
- switch to bg-warning text-warning-foreground (token exists in @etqan/tokens theme.css) in the final fix wave — cost if wrong: colour only.
- fold Task 10 deferred minors (mutation reset, codes-before-error, 409/403 locale mapping) and Task 11 banner colour into Task 12's fix round — same files area, saves a review round — cost if wrong: none.
- Referrer-Policy edge header for /app/quick-login is a Caddyfile change (conductor-only, §3.1): tracked as a request to the conductor; meanwhile the meta tag plus the browsers' default strict-origin-when-cross-origin already keep the token out of cross-origin Referers — cost if wrong: the token can appear in same-origin asset requests' Referer (our own Caddy) until the header lands.

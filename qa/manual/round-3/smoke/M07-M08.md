## Problems

### SMK-M07-01 Session reviews (AR, 1440): "Arabic (Latin)" names wrap with the bracket and hyphen on the wrong side
- Steps: admin AR, 1440x900, `/app/scheduling/reviews`, first row (2026/10/27).
- Screenshot: `qa/manual/screens/r3/smoke/M07-M08/SMK-M07-01-reviews-name-bracket.png` (full page: `m07-reviews-ar.png`).
- Expected: names render like the Sessions and Today lists: «آدم النجار (Adam Al-Najjar)», with the Latin part kept whole.
- Actual: the student cell reads «Adam Al-) آدم النجار» / «(Najjar» and the teacher cell reads «Maryam Al-) الأستاذة مريم الخطيب» / «(Khatib». This is the same class as QA-218/1077.
- Cause (pointer): `dashboard/src/features/reviews/ReviewsList.tsx` lines 175 and 178 print bare `full_name` instead of the shared `PersonName`.
- Console/network: none.

### SMK-M08-01 Invoices list (AR, 1440): the payer column breaks mixed names with the bracket flipped
- Steps: admin AR, 1440x900, `/app/billing/invoices`, row INV-000178.
- Screenshot: `qa/manual/screens/r3/smoke/M07-M08/SMK-M08-01-invoice-payer-bracket.png` (full page: `m08-invoices-ar.png`).
- Expected: the payer column renders the same as the student column next to it, which correctly shows «عمر الشريف (Omar Al-Sharif)».
- Actual: the payer column reads «Mahmoud Al-) محمود الشريف» / «(Sharif», with the bracket on the wrong side and the hyphen at the line end.
- Cause (pointer): `dashboard/src/features/billing/InvoicesList.tsx:239` uses `<bdi>{invoice.payer.full_name}</bdi>` instead of `PersonName`.
- Console/network: none.
